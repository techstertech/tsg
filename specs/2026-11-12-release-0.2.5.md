# TSG 0.2.5 SQLite security patch

## Outcome and scope

Publish TSG 0.2.5 with rusqlite 0.41 and a patched bundled SQLite. This removes
RUSTSEC-2026-0459 from the dependency graph and permits the approved SCS release.
Preserve public APIs, persisted schemas, durability, and application isolation.
Use the existing GitHub release workflow. No service deployment is included.

## Acceptance criteria

1. The locked graph uses libsqlite3-sys 0.39 or newer and no vulnerable bundled
   SQLite remains. Review the dependency tree and hosted supply-chain check.
2. Existing storage, recovery, migration, concurrency, and property checks pass
   with the patched dependency. Run maintained formatting, Clippy, tests,
   documentation, coverage, and package gates.
3. A signed immutable v0.2.5 tag identifies the verified source. The maintained
   release workflow publishes the crate and SHA256SUMS. Download and verify both.

## Risk and recovery

This is a dependency patch with no intended data migration. Existing tests
exercise persisted-store compatibility. Consumers can retain the previous tag
if integration fails, but that version retains the reported vulnerability.
Published versions are immutable; corrections require a new patch version.

## Planned verification

Use Rust 1.98 for local checks. Add no tests for manifest-only changes. Record
executed checks, hosted results, and any skipped checks before sign-off.
